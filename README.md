# 关键帧工坊

在浏览器里把视频拆成关键帧，用于生成画面总结。纯前端运行，文件不上传。

## 在线使用

https://onepro07.github.io/keyframe-studio/

## 功能

- 拖入视频，自动检测画面切换点抽取关键帧
- 感知去重 + 黑屏过滤，避免重复帧
- 一键生成联系表（3×3 拼图，带时间戳）
- 浅色 / 深色双主题
- 全部在浏览器内完成，不联网、不上传

## 本地运行

```bash
python3 -m http.server 8000
```

访问 http://127.0.0.1:8000/

## 技术说明

抽帧走浏览器原生 `video` 元素 + `canvas`，无第三方依赖。

场景判定用 32×18 灰度签名的像素平均绝对差，而不是 dHash ——
实测 dHash 对纯色、渐变、规则棋盘会退化为全 0，导致白→黑这种剧烈切换被误判为无变化。

详见 `使用说明.md`。
